# ORANEO / Pink editorial interface

- Brand name: **ORANEO**, text only. No logo.
- Font: Poppins with system sans-serif fallback. Body 11–13 px, prominent but restrained headings.
- Backgrounds: warm paper `#FBF8FA`, pure white cards, plum navigation `#261521`.
- Accent: vivid rose `#D9367E`; hover `#B92166`; tinted area `#FDE7EF`.
- Strict 0px corner radius everywhere, no gradients, no fake glassmorphism, no floaty shadows.
- Tables use tight left aligned labels and tabular right aligned currency/quantities.
- Spacing and typography carry hierarchy. Icons are functional Lucide icons; no decorative logo.
- Native PDF reports use the same rose accent and retain selectable business text.
- All sales metrics are sourced from the actual SQLite data through API calls.
